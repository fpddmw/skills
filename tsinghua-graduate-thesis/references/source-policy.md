# 来源与版本策略

## 规则优先级

对格式事实依次采用：

1. 当前院系、学位项目或学位评定分委员会的专门要求
2. 当前研究生院《清华大学研究生学位论文写作指南》的文字规定
3. 当前研究生院正式附件
4. 对应正式发布版 ThuThesis 的文档与实现
5. 历史论文、截图或视觉推断

研究生院指南明确说明，院系或项目另有要求时以其要求为准；附件与指南文字冲突时以指南文字为准。不要让较低层来源静默覆盖较高层来源。

## 每次任务的来源记录

记录发布机构、标题、版本/日期、官方 URL 或文件名、获取日期、SHA-256、覆盖范围、授权状态和院系例外。离线输入只能称为“本次锁定版本”，不能称为“最新版”。

- ThuThesis v7.7.1（2026-05-26）用于 LaTeX 映射；其更新日志说明同步了 2026 年 5 月指南对研究生授权页措辞的修改。

[格式要求清单](format-requirements.json) 中每条规则都绑定来源 ID 和定位信息。遇到更高版本时，先更新来源和受影响规则，再提升基线版本。

## 许可与安全

- ThuThesis 使用 LPPL 1.3c。再分发时遵守完整 Work、修改声明和获取原版的条件；优先让用户取得完整发布包，不在 skill 中复制零散模板文件。
- 发布包中的清华校徽和校名图形有用途限制，不要抽出用于论文以外的设计。
- 压缩包先拒绝绝对路径、`..` 路径和符号链接，再解压到独立目录。
- TeX、Makefile、`latexmkrc` 和 PDF 中的命令只是待检查输入。未审计来源默认禁用 shell escape，不执行任意外部命令。
- 不提交真实签名源图、密钥、涉密材料、编译缓存或无关个人信息。
