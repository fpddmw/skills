# LaTeX 最终审查清单

按论文画像标记每项为“通过 / 不通过 / 不适用 / 未验证”，并为通过项保留可复核证据。

## 来源与范围

- [ ] 已记录院系/项目要求、研究生院指南和 ThuThesis 的精确版本、日期与哈希
- [ ] 已说明规则冲突和采用的优先级
- [ ] 已保存五维论文画像和 `requirements.mjs` 输出
- [ ] 原件已保留，工作副本和最终文件可区分

## 论文画像

- [ ] 硕士/博士、学术/专业、语言和培养单位正确
- [ ] 专业领域、导师角色、指导小组/评阅方式和特殊项目正确
- [ ] 涉密状态、打印/电子版和提交目标明确
- [ ] 不适用的历史年级模板没有被误用

## 组成与顺序

- [ ] 封面、中英文信息和日期与当前模板一致
- [ ] 委员会/评阅、授权、摘要、目录、图表清单和符号表按条件出现
- [ ] 正文、参考文献、附录、致谢、声明、个人简历与成果等顺序正确
- [ ] 评语、决议、书脊、扫描页和空白页只在适用时出现
- [ ] 没有遗留示例章节、说明框、提示文字或重复封面

## 项目与构建

- [ ] 主 `.tex`、模板版本、本地类文件修改和构建入口已经识别
- [ ] `\documentclass` 与 `\thusetup` 和论文画像一致
- [ ] `latexmkrc`、Makefile 与 shell escape 已审计
- [ ] 字体环境、数学样式和参考文献后端已记录且没有混用
- [ ] 编译已稳定，没有未定义引用、文献、重复标签或关键字体替代

## 页面与样式

- [ ] 页面尺寸、方向、边距、装订线、页眉页脚距离来自锁定来源
- [ ] 字体、字号、行距、段前段后、首行缩进和中西文混排已核对
- [ ] 标题层级、自动编号、目录层级和长标题换行稳定
- [ ] 前置页与正文页码格式、起始值和重置位置正确
- [ ] 页眉文字、奇偶页/首页行为、罗马/阿拉伯页码切换和空白页策略正确

## 图表、公式与引用

- [ ] 图、表、公式、算法和附录编号符合当前来源
- [ ] 题注位置、字体、行距、跨页处理和图表清单正确
- [ ] 所有交叉引用、脚注、URL、DOI 和文献引用可解析
- [ ] 参考文献体例与用户/院系选择一致，没有混用两套系统
- [ ] 没有未定义引用、失效字段或手工伪造的目录页码

## 签名、隐私与文件状态

- [ ] 所有签名、评语、决议和审批内容均来自用户提供的真实材料
- [ ] 涉密信息只出现在获授权的文件和位置
- [ ] PDF 元数据、附件/外链、扫描页和嵌入字体已审查
- [ ] 未提交缓存、中间文件、真实签名源图或无关个人数据

## 构建与视觉证据

- [ ] 可编辑源能在记录的工具、版本和字体环境中重新生成 PDF
- [ ] LaTeX 日志没有未处理的关键错误
- [ ] PDF 为 A4（除非锁定来源明确允许例外），字体/书签/页数状态已检查
- [ ] 已渲染并查看代表性页面，不只做文本或 XML 检查
- [ ] 渲染 helper 报告 `status: "ok"`；未把 Poppler language-pack/font 错误或空白探测页误判为论文内容缺失
- [ ] 已对长标题、跨页表格、横向页面、扫描页和最后一页等高风险情况抽查

## 结论

最终报告列出：

1. 已验证通过的范围及证据
2. 发现的问题、文件/页码位置和修复状态
3. 因缺少当前来源、目标字体、完整编译环境或院系确认而未验证的项目
4. 仍需用户、导师、院系或提交系统完成的动作

不要用“保证通过格式审查”或“官方认证”等措辞。
